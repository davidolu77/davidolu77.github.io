# davidolu77.github.io

Public source for `davidolutunde.com`, hosted with GitHub Pages.

## Website Files

The website runs from the static files in this repository:

- `index.html`
- `posts.html`
- `projects.html`
- `posts/`
- `projects/`
- `images/`
- `*.css`
- `CNAME`
- `site.webmanifest`
- `sitemap.xml`

## Deployment

There is no build step. GitHub Pages serves the HTML, CSS, images, and supporting static assets directly from this repository.

## Public Repository Note

Everything committed here is public. Only website files and assets intended for public viewing should be pushed.

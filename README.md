# davidolu77.github.io

Source for `davidolutunde.com`, hosted on GitHub Pages from this public repository.

## Public Repo Rules

Everything committed here should be treated as public.

- Do not commit passwords, API keys, tokens, recovery codes, `.env` files, or private config files.
- Do not commit admin screenshots, invoices, unpublished drafts, or documents with personal addresses or phone numbers unless you want them public.
- Keep analytics IDs, social links, and normal site assets only if you are comfortable exposing them.
- If a feature needs a secret key, move that feature to a backend or serverless function outside GitHub Pages.
- Review new files before pushing, especially images, PDFs, ZIP files, and exported notes.

## Security Notes

This site is a static website, so visitors cannot read your GitHub account from the site itself. The main risk is publishing something sensitive in the repository by accident, or losing access to your GitHub/GoDaddy accounts.

Recommended account protections:

- Enable GitHub 2FA and GoDaddy 2FA.
- Use a strong unique password for both accounts.
- Keep the GitHub repository public only for files you are happy to make public.
- Review GitHub Pages, domain DNS, and GitHub Actions settings occasionally.

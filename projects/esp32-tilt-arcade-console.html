ESP32 Tilt Arcade Console

Published: July 27, 2026

This project takes my earlier Arduino Nano tilt consoles and rebuilds them around an ESP32. The extra memory and processing power made it possible to combine four games, a particle fluid simulator, and an animated robot face in one compact OLED system.

The console is controlled by tilting an MPU-6500 motion sensor. One push button handles the menu and in-game actions, while a passive buzzer provides sound feedback.

📸 Preview

⚙️ How It Works

  • The ESP32 runs the menu, all six modes, sound effects, calibration, and saved scores.
  • The OLED and MPU-6500 share the ESP32's I2C bus on GPIO21 and GPIO22.
  • The firmware converts live accelerometer readings into movement or simulated gravity.
  • Each mode stores its own neutral tilt calibration in EEPROM.
  • High scores are saved for Coin Collector, Tilt Snake, and Space Dodger.
  • A single button supports short, long, and very long presses for different actions.
  • The Vector Face reacts to tilt, cycles expressions, blinks, and responds to shaking.

🎮 Games and Modes

🚀 Building and Uploading

  1. Install PlatformIO in VS Code.
  2. Clone or download the project repository.
  3. Open the repository folder in VS Code.
  4. Connect the ESP32 by USB.
  5. Build the project with PlatformIO.
  6. Select the detected serial port and upload the firmware.
  7. Hold the console in a comfortable position and recalibrate each mode if needed.
[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino
monitor_speed = 115200
lib_deps =
  adafruit/Adafruit SSD1306
  adafruit/Adafruit GFX Library

📝 Notes

  • The tested board was an ESP32 Dev Module with an ESP32-D0WD-V3 chip, 4 MB flash, and a CH340 USB interface.
  • The OLED address is 0x3C, and the IMU is checked at 0x68 and 0x69.
  • Use 3.3 V for the OLED and IMU in this ESP32 build.
  • The ESP32 provides much more memory headroom than the Arduino Nano versions.
  • The repository contains the complete firmware but currently requires a final licensing review before reuse terms are formally stated.
